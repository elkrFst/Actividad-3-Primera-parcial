METODO DE LAS DOS FASES

El procedimiento consiste en resolver el modelo en dos 
etapas o fases.

• Se usa ante la presencia de variables artificiales en el
modelo a solucionar y su objetivo es eludir el uso de la
constante M, aquella que definimos como un número muy
grande aunque finito.

• Paso Inicial: Se revisan las restricciones del problema
original introduciendo variables artificiales según se
necesite para obtener una solución básica factible inicial
obvia para el problema artificial.



Fase I

 Uso del método simplex para resolver el problema de 
programación lineal.

 Minimizar Z = Σ de variables artificiales, sujeta a las
restricciones revisadas. La solución óptima que se
obtiene para este tipo de problemas (con Z = 0) será
una solución básica factible par el problema real.



Fase II

 Se eliminan las variables artificiales (estas en esta fase
valen 0). Comenzando con la solución BF que se
obtiene al final de la fase I, se usa el método simplex
para resolver el problema real. A continuación se

RESUMEN DEL METODO SIMPLEX REVISADO
1. Paso Inicial: El mismo que  para el método simplex original
2. Paso iterativo:

Parte 1  Determinar la variable básica entrante

Parte 2 Determinar la variable básica que sale igual que para 
el método simplex original, pero se calcula sólo  los números 
que se necesitan para hacerlo (los coeficientes de la variable 
básica entrante en todas las ecuaciones menos la ecuación 
(0), y después, para cada coeficiente estrictamente positivo, 
se calcula el lado derecho.)



Parte 3 Determinar la nueva solución básica factible:
obtener B-1 y el conjunto XB = B-1b.( El cálculo de XB es
opcional, a menos que la prueba de optimalidad encuentre
que es 0ptima.)

3. Prueba de optimalidad : igual que para el método
simplex original, excepto que se calculan sólo los
números necesarios para realizar esta prueba, a saber,
los coeficientes de las variables no básicas en la
ecuación (0).
